# Microwave Coffee Roasting Principles

## 煎りムラ対策

マイクロ波を使用した調理は、必ず加熱ムラが発生する。   
コーヒー豆を調理対象(焙煎)とした場合でもそれは変わらない。  
コーヒー豆の温度分布の偏りを低減させるための工夫を積み重ねる必要がある。  

| | |
| ---- | ---- |
| 工夫-1 | 焙煎工程冒頭の 低ワット 300W 照射 |
| 工夫-2 | 高ワット 800W と 中ワット (500W or 600W) を交互に使用する時間区間を設ける |
| 工夫-3 | マイクロ波の照射と照射の間に必ず容器を手で振り、豆を撹拌する |

## マイクロ波の連続照射時間

連続して長時間 マイクロ波を照射し続けると、コーヒーの味が悪くなる、という経験則がある。  
コーヒーの味が荒れるのを防ぐため、2つのルールを設ける。  

| | |
| ---- | ---- |
| ルール1 | Ws (ワット秒)でいうと、連続して 25000 Ws を超えて マイクロ波を照射すべきでない |
| ルール2 | 連続して 60s 以上の連続照射は避ける |

上記 2つのルールを マイクロ波のワット数ごとに適用すると以下のようになる。  

| | |
| ---- | ---- |
| 300W の場合 | 連続 60s が上限。 それ以上連続して 照射すると コーヒーの味が荒れる |
| 500W の場合 | 連続 50s を上限と定める |
| 600W の場合 | 連続 40s を上限と定める |
| 800W の場合 | 連続 30s を上限と定める |

マイクロ波の照射と照射の間に必ず容器を手で振って、豆を撹拌することで  
加熱温度ムラを低減し、豆の温度の均一化を目指す。   


## 焙煎豆の体積変化量の遷移を焙煎進行のコントロールに利用する

焙煎の進行に従い、コーヒー豆の体積は変化する。  
その体積量の変化推移を焙煎進行コントロールへ積極的に利用する。

| フェーズ | 体積変化 |
| ---- | ---- |
| Phase-1 | 体積が増える。 生豆に含まれている水分が加熱され気化しようとすることで豆の体積が膨張する |
| Phase-2 | 体積が減る。 生豆の水分が蒸発し、豆は収縮する |
| Phase-3 | 体積が増える。 1ハゼ開始前に豆の体積は膨張を始める。 1ハゼが始まると体積が大きく増える。<br>1ハゼと2ハゼの間は いったん体積変化は少なくなり、2ハゼが始まるとまた体積が1段 増加する |

## 使用するワット数と適用への考え方

| 使用するワット数 | いつ使う | 考え方 |
| ---- | ---- | ---- |
| 300W 60s | 焙煎開始から、水の沸点の少し手前 90℃ 程度まで | 煎りムラ対策で冒頭は時間をかけて加熱してゆく | 
| 800W 30s/600W 40s を交互に照射するパターン | 豆の温度が 90℃ (沸点直前) を超えた後、焙煎初期 | 800W 30s を織り交ぜてしっかり加熱したい。 600W 40s と交互にすることで早くに焦げてしまうことを避ける |
| 800W 30s/500W 50s を交互に照射するパターン | 同上 | 600W 40s パターンより 500W 50s パターンの方が熱量が多くなる。 Washed 精製に使う |
| 600W 40s のみ、あるいは 500W 50s のみ | 豆が1粒でも薄く色づき始めてから、1ハゼ前まで | 豆の表面が色づき始めたら 高ワット (800W) は控え、中ワット帯 (500W、600W) を使う |
| 800W 20s/600W 20s を交互に照射 | 1ハゼ開始直前から1ハゼ終了まで | 1ハゼをしっかり進行させるには熱量が必要である。 高ワット (800W) を織り交ぜて進行を促進する |
| 600W 15s | 1ハゼ終了から焙煎終了まで | 焙煎最終段階、どこまで焙煎を進めたいかで、600W 15s を何回繰り返すかを決める | 

あまり難しく考えないこと。  
もし 800W/500W/600Wを交互に切り替えて焙煎を進行させるのが面倒に感じたら、  
600W などを一貫して使用しても結局のところ焙煎は可能である。  
経験を積みながら、自分でやりやすいと思う方法を見つけてほしい。 楽しく継続するのが一番である。

## natural (sun dry) と washed 精製豆の振る舞いの違い

natural 精製と Washed 精製の生豆には典型的な振る舞いの違いがある。

| 比較対象 | natural | washed |
| ---- | ---- | ---- |
| 水洗でとれる チャフの量 | Washed と比べると多い | Natural と比べると少ない |
| 浸水後の吸水量 | 144g -> 183g 程度 | natural と比べると多く吸水することが多い |
| 必要な熱量 | 440k Ws 前後 | natural と比べると必要とする熱量は多くなることが多い |
