# Microwave Roasting 実践 汎化説明

## 前提 (step-0)

本ドキュメントで使用する microwave ワット数, 時間は
すべてコーヒー生豆を焙煎前に洗浄し, 
30分間 50℃のお湯で吸水させている状態でスタートしている.

生豆の洗浄, 吸水は 電子レンジ microwave 焙煎手法とは
直接的な関係はなく, あなたの好みによって行ってもいいし, 
行わなくてもよいオプションだ.

筆者は常に焙煎前に生豆の洗浄, 30分間の吸水(はちみつ + 果糖溶液) を行うという理由から
本ドキュメントで紹介する実例で出す ワット数, 時間は
すべてこれらの作業を済ませた前提の上に成り立つ数字であることに注意されたい.

洗浄, 吸水はなくてももちろん 電子レンジ microwave 焙煎はできるので, 
あなたが 生豆洗浄, 吸水しない選択をした場合には, 
あなた自身で適切な microwave ワット数, 時間を見つけ出して欲しい. 
きっともちろんそれはあなたにとって新たな発見に満ちた楽しい工程であるに違いないのだから.

## step-1 容器にフタをする

生豆の温度を速やかに上昇・維持しながら焙煎を進行させるために
容器にはフタをする.

## step-2 木製割りばしを台座にしてシリンダをセット

木製割りばしをレンジ底面に置きそのうえに
生豆を入れたホウケイ酸ガラス製シリンダをセットする

## step-3 焙煎スタート 低ワットで 100℃ まで

microwave 焙煎スタート.

コーヒー生豆に限らず, microwave を使用した食材の加熱は
必然的に加熱ムラを生じさせる. 

microwave を使用したコーヒー豆焙煎においても, 
コーヒー豆の温度分布の偏りを低減させるための工夫を積み重ねる必要がある.

加熱ムラを低減させるための施策の1つとして, 
焙煎工程冒頭で, 低ワット数 (300W) で 100℃ (水の沸点) 少し手前まで (90℃) 加熱する.

30分給水後, 180 - 200g 程度になった生豆を 100℃ 手前までもってゆくのに
300W 1分 を4セット. 

300W １分おきに生豆を入れた容器を電子レンジから取り出し, 
容器を手で振って生豆を撹拌する. 撹拌し, 次の micro 波 が
スタートするまでの時間は約 30秒程度.

300W を 1分照射, 30秒撹拌 を4セット. 
4セットを済ませると 生豆の温度は 90℃程度になっている.

| ワット | 照射時間 | 撹拌インターバル |
| ---- | ---- | ---- |
| 300W | 60s| 25-30s |
| 300W | 60s| 25-30s |
| 300W | 60s| 25-30s |
| 300W | 60s| 25-30s |


## step-4 本格加熱開始 高ワット+中ワットを併用する

300W 1分 microwave 照射 + 撹拌 4セットの後,
高ワットを使用し, 豆の温度を速やかに上昇させ吸水した水分を飛ばしてゆく. 
著者の使用する Panasonic 社製 家庭用電子レンジの最高ワット数は 800W なので
本稿での "高ワット" とは 800W である.

速やかに温度を上昇させるため, 800W (高ワット)を組み入れる.
しかし 800W を連続照射すると豆が早くに焦げてしまうので
中ワット (500W, 600W) と交互に照射することで
焙煎進行が急激に進みすぎることを防ぐ.

Natural (sun dried) 精製豆の場合, 熱の入りが早い. 
Washed 精製豆の場合, より多く吸水し, そして Natural精製の豆と比較して, 温度上昇により多くの熱量が必要になる.

生豆に高い熱量をしっかりとかけるチャンスがあるのは, 焙煎工程の前半だ. 
焙煎工程前半でしっかり熱量をかけることを心掛ける.

### microwave 照射パターン 1: Natural 精製豆の場合 

Natural 精製豆 は Washed 精製と比べると熱の入りが早いことが多いことを念頭に置く.

800W -> 600W -> 800W -> 600W とm 高ワット (800W), 中ワット (600W) を
交互に照射する. 
照射時間, 撹拌時間を考慮に入れると

| ワット | 照射時間 | 撹拌インターバル |
| ---- | ---- | ---- |
| 800W | 30s | 25-30s |
| 600W | 40s | 25-30s |
| 800W | 30s | 25-30s |
| 600W | 40s | 25-30s |

となる. このバターンは浅煎りを目指す場合に利用する.

### microwave 照射パターン 2: Natural 精製豆で, やや熱量を必要とする場合 

Natural 精製豆 は Washed 精製と比べると熱の入りが早いことが多いことを念頭におきつつ,
パターン1 よりは熱量を入れる必要があるケースは
800W 30s, 500W 50s, 600W 40s を併用する.

照射時間, 撹拌時間を考慮に入れると

| ワット | 照射時間 | 撹拌インターバル |
| ---- | ---- | ---- |
| 800W | 30s | 25-30s |
| 600W | 50s | 25-30s |
| 800W | 30s | 25-30s |
| 600W | 40s | 25-30s |

となる. このバターンは中煎りを目指す場合に利用する.

### microwave 照射パターン 3: Washed 精製の場合

かける熱量を増やす必要がある.
500W 50s (= 2500 Ws) を使う.

| ワット | 照射時間 | 撹拌インターバル |
| ---- | ---- | ---- |
| 800W | 30s | 25-30s |
| 500W | 50s | 25-30s |
| 800W | 30s | 25-30s |
| 500W | 50s | 25-30s |

となる. これは中深煎り以降を目指す場合に利用する.

焙煎容器を振って撹拌, その後 フタを一瞬開けて排気して, すぐふたを戻す.
以降, 撹拌時にはこのフタを開閉する排気を毎回行う.

## step-5 焙煎進行 中ワットで 1ハゼ Ready まで

500W 50s, 撹拌 (25-30s) 及び
600W 40s, 撹拌 (25-30s) を使い
1ハゼ前まで進行させる.

### 例1: まず 500W 50s, 後に 600W 40s を使う場合

熱量が必要な Washed 精製で使う.
焙煎工程のまだ早い段階で 50s 連続照射により加える熱量を稼ぐ.

| ワット | 照射時間 | 撹拌インターバル |
| ---- | ---- | ---- |
| 500W | 50s | 25-30s |
| 500W | 50s | 25-30s |
| 500W | 50s | 25-30s |

| ワット | 照射時間 | 撹拌インターバル |
| ---- | ---- | ---- |
| 600W | 40s| 25-30s |
| 600W | 40s| 25-30s |
| 600W | 40s| 25-30s |

とする. 中煎り, 中深煎りを目指す場合に利用する.

### 例2 500W 50s を使わず, 代わりに 600W 40s で通す場合

焙煎進行の早いナチュラル精製の豆で使う.

| ワット | 照射時間 | 撹拌インターバル |
| ---- | ---- | ---- |
| 600W | 40s | 25-30s |
| 600W | 40s | 25-30s |
| 600W | 40s | 25-30s |

| ワット | 照射時間 | 撹拌インターバル |
| ---- | ---- | ---- |
| 600W | 40s | 25-30s |
| 600W | 40s | 25-30s |
| 600W | 40s | 25-30s |

とする. 中浅煎りを目指す場合に利用する.

焙煎進行の早いナチュラル精製の場合
ここまでに 体積増 (転換点) フェーズに到達することが多い.
ウオッシュ精製は熱量が必要なので 次の step-6 が必要になることが多い. 

## step-6 1ハゼ開始前の一押し　(Optional)

step-5 までで 体積増 (転換点) に転じない場合には, 

| ワット | 照射時間 | 撹拌インターバル |
| ---- | ---- | ---- |
| 600W | 30s | 25-30s |

を 1, 2回繰り返す.
「体積増に転じる」段階まで持ってゆくことが step-6 の目的である.

## step-7 高ワットの使用でハゼを促進

1ハゼ煎りをキックするために, 高ワット 800W 20s を入れる.
連続して 800W を照射すると, 焙煎工程が急激に進みすぎるので, 
間に 600W 20s を入れ, 焙煎時間を延ばしきっちり豆に火が通るようにする.

| ワット | 照射時間 | 撹拌インターバル | Note |
| ---- | ---- | ---- | ---- |
| 800W | 20s | 25-30s |
| 600W | 20s | 25-30s |
| 800W | 20s | 25-30s | このあたりで 1ハゼスタート目標 |
| 600W | 20s | 25-30s |


ここまでで, 強い 1ハゼが起こっていれば, 800W 照射はしない.  
もし 1ハゼが弱ければ, もう１回 800W 照射工程を入れる.

| ワット | 照射時間 | 撹拌インターバル | Note |
| ---- | ---- | ---- | ---- |
| 800W | 20s | 25-30s | もし 1ハゼがはっきり進行していれば 15s にする |
| 600W | 20s | 25-30s | ぼちぼち 1ハゼがおとなしくなる |

## step-8 最終段階 いつ焙煎を止めるかを判断する

| ワット | 照射時間 | 撹拌インターバル | Note |
| ---- | ---- | ---- | ---- |
| 600W | 15s | 25-30s | 2ハゼまで深く焙煎したい場合は 20s |
| 600W | 15s | 25-30s | 2ハゼまで深く焙煎したい場合は 20s |
| 600W | 15s | 25-30s | 2ハゼの予兆あり |
| 600W | 15s | 0s |ハゼの予兆あり, 焙煎終了 |

2ハゼを深く入れたい場合は, 600W 15s, 撹拌をもう 1,2 セット入れ
満足したら焙煎終了とする.

## step-9 焙煎豆を焙煎容器からトレイに空ける

焙煎豆を焙煎容器からトレイに空けたら, すぐに温度計測する.

| 焙煎度 | 計測温度 | Note |
| ---- | ---- | ---- |
| 中浅煎り | 205℃ 前後 | |
| 中煎り | 215℃ 前後 | |
| 中深煎り | 225℃ - 229℃ 前後 | 230℃近いとだいぶ深い. 豆はテカテカになる |

最終的に温度が何度になったか, というより, 
200℃ を超えた時間をどの程度継続させたか, 
によって豆の焙煎度が決まる. 

仮に 最終温度が 203-205℃程度であったとして, 
800W 20s, 600W 20s の組み合わせ工程 (step-7) できっちり 1分半前後
時間を稼いだ場合と, あっという間に 200℃を超え, マイクロ波照射時間を
稼げなかった場合とでは, 焙煎後の豆の様相は異なる.

どちらかが絶対的に正しい、ということはない.
が, 筆者の経験では, きっちり 1分半前後時間を稼いだ場合の方が, 
自分好みの味になることが多い. 
これは自分で味を評価して判断すればよい.

トレイにあけて温度を計測したら, すぐ空冷をはじめる. 
速やかに 30℃程度まで温度を下げる. 

これで焙煎終了である.
