# spreadsheet note interpretation

## 1. 体積遷移記載法 解説

体積は焙煎用のホウケイ酸ガラスのシリンダを器として使用している.
そして体積の読み取りは人間が目視で都度行っているので厳密なものではないことに留意.

シリンダに書かれた体積目盛り25ml 間隔であることから
25ml より小さい体積量変化を表現するための表記法を以下のように用いている.

| No. | 体積量 記載例 (単位: ml) | 意味 |
| ---: | --- | --- |
| 1 | 275/300 | 体積がだいたい 275ml と 300ml の間くらにある, という意味. グラフでプロットするときは  287.5 でよい |
| 2 | 275+ | 275ml より少しだけ体積が多い. でも 275/300 (275ml と 300ml の間) よりは少ない状態 |
| 3 | 275- | より少しだけ体積が少ない. でも 250/275 (250ml と 275ml の間) よりは 275ml に近い状態 |

体積の変化の表記は, 275ml 近辺を例にとると  
250 → 250+ → 250/275 → 275- → 275 → 275+ → 275/300 → 300- → 300 の順で遷移を表現している.

## 2. spreadsheet の note 文言 解説

注記で使用している文言のなかで, 意味がとりづらいと思われるものについて
その解釈を列記する. この内容を踏まえた上で, スプレッドシートの焙煎進行を読み取ってほしい.

| No. | 状況・特記事項 | 解釈 |
| ---: | --- | --- | 
| 1 | 排気開始| 撹拌のために電子レンジからシリンダを取り出したとき1度だけフタをパカパカと開け閉じをする動作.<br>明示していなくても以降のステップでは毎回行っている. |
| 2 | カナリア豆 | 焙煎進行初期段階でまだ全く色づいていない状態から, 他の豆に先駆けて1粒だけ茶色に色づくものが出てくるタイミングを指す. 高出力ワット (800W) 照射をやめるタイミングの指標になる |
| 3 | 色づきはじめ | 焙煎が進行し, 複数の豆がうっすら茶色く色づき始めた状態 |
| 4 | まだら, 薄くまだら | 色づき始めの状態よりさらに焙煎が進行し, 豆全体が茶色く色づいてきているが, まだ色の薄いもの, 濃いものがまじりあってまだらになっている状態 | 
| 5 | 単ハゼ | 1回だけ "プスン" とハゼ音が聞こえた状態. まだ「1ハゼが始まった」とは言えない状態 |
| 6 | 転換点 | 体積が減少から増加に転じたステップ. 1ハゼ直前であることを示唆している |
| 7 | しーん | 1ハゼを進行させるために 高出力 (800W) 20s の照射をはじめたが, まだ1ハゼがはじまらない, 静かな状態 | 
| 8 | プス, プスプス, パチ, プチ, パチパチ | 連続したハゼというには弱く, プスプス, 或いは パチパチ という音を豆が出している状態. 1ハゼ直前, あるいは1ハゼがそろそろ終わる, あるいは 2ハゼ直前の状態 | 
| 9 | ブリブリ, プリプリ | 勢いよく豆がハゼていることを表す プリプリよりは ブリブリの方がハゼの勢いが強い |
| 10 | 2ハゼの予感 | 単発で 高い音の 弱いハゼ音が聞こえる状態. 2ハゼスタートとはまだ言えない |
| 11 | 2ハゼ はっきり | "2ハゼの予感" を超えて焙煎が進行し, はっきり2ハゼが起こっている状態 |
